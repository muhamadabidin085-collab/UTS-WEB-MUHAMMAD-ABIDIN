## 📌 Deskripsi Proyek
Proyek ini merupakan *Interactive Personal Portfolio & Dashboard Web Page* interaktif yang memuat profil profesional, keahlian, showcase proyek, modul kalkulator estimasi biaya proyek, serta formulir kontak terinteraktif yang responsif.

Web ini dibangun untuk memenuhi kriteria Ujian Tengah Semester (UTS) Ganjil Mata Kuliah Pemrograman Web di Universitas Nusantara PGRI Kediri.

---

## 🚀 Fitur Utama
1. **Semantik HTML5 & Responsif:** Menggunakan tag semantik HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`) serta kerangka kerja Bootstrap 5.
2. **Dark Mode Toggle:** Beralih antara mode terang (*light*) dan mode gelap (*dark*) secara interaktif dengan penyimpanan preferensi di `localStorage`.
3. **Modul Kalkulator Estimasi Biaya:** Menghitung estimasi biaya pembuatan proyek website secara otomatis dan terkonversi ke format IDR secara langsung (*DOM Real-time Update*).
4. **Pencarian & Filter Proyek:** Pencarian langsung karya/proyek berdasarkan judul atau teknologi.
5. **Validasi Formulir Kontak:** Penanganan validasi formulir di sisi klien menggunakan JavaScript sebelum data dikirimkan.
